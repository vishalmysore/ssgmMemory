User as Code arXiv:2606.16707

An interactive, training-free implementation of User as Code (UaC) — instead of a "bag of facts" you retrieve over, the agent's model of a user is a living software project: an append-only fact log is periodically compiled into typed state + executable rules. Rules fire deterministically on change (drug–allergy safety), and questions are executed over the whole history — so aggregation is exact, where retrieval can only recall snippets.
