Chain-of-Memory arXiv:2601.14287

An interactive, training-free implementation of Chain-of-Memory (CoM) — lightweight construction paired with sophisticated utilization. Memory is stored as cheap distilled units; at query time, instead of dumping the Top-K matches, CoM links fragments into an ordered multi-hop reasoning chain, recovering the bridge fragments a query-only search misses. The chain drives dynamic evolution and adaptive truncation to keep memory bounded.

Reported in the paper: CoM improves accuracy by 7.5–10.4% over strong baselines while using ≈ 2.7% of the tokens and 6.0% of the latency of heavy graph-memory construction — lightweight to build, sophisticated to use.

Lightweight Memory Store distilled units + cheap metadata

Each interaction is distilled into a small unit (content + tags + importance). The chain reinforces traversed units (access ↑, importance ↑); adaptive truncation prunes the lowest importance × recency × log(access) when over capacity.
