An interactive, training-free implementation of Stability & Safety Governed Memory — a governance layer that decouples memory evolution from execution. Every write passes a contradiction gate against protected core facts M_core; every read is filtered by access control, Weibull freshness and provenance; the mutable graph is bounded against an immutable ledger K_ledger and can be rolled back. No model, no weights — pure logic.
